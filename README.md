# HJ-Ok.github.io

Personal academic homepage of Hyunjong Ok, built with Jekyll ([minimalist](https://github.com/BDHU/minimalist) theme).

- **Live site**: <https://hj-ok.github.io>
- **Content**: `index.md`
- **Title / sidebar links / analytics**: `_config.yml`
- **Layout & styles**: `_layouts/`, `_includes/`, `_sass/`, `assets/`

## Local preview

With Docker:

```bash
./deploy.sh
# then open http://localhost:4000
```

The site is deployed automatically by GitHub Pages on push to `main`.
